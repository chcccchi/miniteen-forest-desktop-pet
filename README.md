# Miniteen Forest Desktop Pet


一个使用 Godot 4 制作的桌面宠物养成原型。项目把日常键盘输入转化为金币，并通过阶段目标解锁不同宠物，让桌面陪伴与真实使用行为形成轻量循环。

## 核心玩法


- 记录键盘输入次数，并按规则换算金币。
- 使用金币解锁不同宠物，形成持续养成目标。
- 宠物常驻屏幕底部，小屋界面承载解锁与管理功能。
- 支持置顶、透明窗口和鼠标穿透等桌面交互。
